# Studio de Beleza & Estilo

Jogo 3D em terceira pessoa (Three.js, um único arquivo HTML) de uma cabeleireira e estilista num bairro real de Maceió.

**Jogar:** https://studio-beleza-estilo.vercel.app

- WASD/joystick para andar, mouse/arrastar para girar a câmera
- E na cadeira para atender a cliente; V troca 1ª/3ª pessoa; P pausa
- Funciona no celular (em pé ou deitado) e pode ser instalado como app
